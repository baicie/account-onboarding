Alerts & durable outbox

At-least-once delivery; duplicate delivery is possible after a crash. Reconcile updates the alert set from current metrics. Dispatch sends currently due outbox rows. Resolve closes active rows without sending. None of these is a retry/re-arm of Delivered or Dead Letter history.

Reconcile

Evaluates current metrics, enqueues new active alerts, and resolves active rows whose rule disappeared. Does not send.

Dispatch due rows

Claims due PENDING/RETRY_PENDING rows and calls the configured transport. Delivered/Dead Letter/Resolved rows are not re-sent.
