## 实际交付

### Alerts / Durable Outbox UI

- `/ui/alerts/outbox`：真实 SQLite 查询，状态计数（PENDING/IN_FLIGHT/RETRY_PENDING/DELIVERED/DEAD_LETTER/RESOLVED）、状态筛选、offset 分页、空状态、transport fail-closed 提示。
- `/ui/alerts/outbox/{id}`：Alert/Delivery ID、attempts、lease/next attempt、last error、delivery history。
- **Reconcile**：评估 metrics 并更新 durable outbox，不发送。
- **Dispatch**：仅 due 行，无 transport 时 disabled + 后台拒绝。
- **Resolve**：只关闭 PENDING/IN_FLIGHT/RETRY_PENDING。
- **Re-arm**：独立操作，只把 DELIVERED/DEAD_LETTER 转为 RESOLVED，保留 delivery history；之后 Reconcile 才能创建新 active alert。
- 所有 mutation 走 CSRF、UI auth 和 audit。
