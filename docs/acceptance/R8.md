## 6. P4 — 外部资源对账

Cloudflare 创建地址是远端副作用，不能与本地事务共享事务；系统不声称 exactly-once：

- 复用 append-only event log（ADR `docs/adr/0001-external-operation-reconciliation.md`）：`EXTERNAL_OPERATION_PREPARED`（调用前、失败则不调用 provider）→ `CONFIRMED`（与成功 Step 提交同事务）或 `OUTCOME_UNKNOWN` / `RECONCILIATION_REQUIRED` / `FAILED`。
- 字段：run/step、operation_key、provider、operation_type、截断 SHA-256 request fingerprint、status、attempt、error_class；allowlist + redaction，无 token/JWT/地址/完整响应。
- Admin-only `GET /v1/ops/external` 返回 items/counts/needs_reconciliation；无 secret。
- 测试：成功 CONFIRMED；超时 → OUTCOME_UNKNOWN；重复地址 → RECONCILIATION_REQUIRED；admin 200/viewer 403；既有 Cloudflare 重复 fail-closed 测试保持。
- 不支持自动删除/自动二次创建；人工对账为唯一处置路径。
