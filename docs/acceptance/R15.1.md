## B. Outbox

- `ResolveAlertOutboxMissing` 不再 `ListAlertOutbox(500)`；改为单事务 temp current-rule 集合 SQL，只处理 PENDING/IN_FLIGHT/RETRY_PENDING；delivery history 与 outbox 同步原子 RESOLVED。
- 测试：100 active behind 600 resolved；1 active +1000 delivered；1000 active 按规则保留；in-flight；Resolve/Claim 并发；关闭重开 700 active。全部 PASS。
- DELIVERED/DEAD_LETTER 不自动 Resolve 的现有契约保持不变；需要显式 Resolve 才能 rearm。
- 仍不承诺 exactly-once；at-least-once + AlertID/DeliveryID 幂等。

## C. Webhook

- Pinned DialContext：解析 → 校验每个 A/AAAA → 连接选定 IP；TLS 使用原 hostname；Proxy 固定 nil，不继承环境代理。
- 拒绝 loopback/private/link-local/metadata/CGNAT/mapped IPv6/unspecified/multicast/0.0.0.0/8/240.0.0.0/4/NAT64/6to4/TEST-NET。
- 无 redirect；TLS 证书校验；DNS 解析失败、混合 allowed/disallowed 记录、证书不匹配、代理注入均有测试。
- 4xx 永久（除 408/429）→ DEAD_LETTER；408/429/5xx/network/timeout → RETRY_PENDING；2xx DELIVERED。
- DeliveryEnvelope：stable AlertID logical identity + attempt DeliveryID；webhook headers/JSON/idempotency key；HMAC over exact body。
- Circuit breaker + response cap + timeout。
