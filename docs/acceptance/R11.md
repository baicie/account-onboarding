## 2. P0 — UNRESOLVED 决议语义（核心修复）

- `UNRESOLVED` 是**审核**而非关闭：保留 `OUTCOME_UNKNOWN` / `RECONCILIATION_REQUIRED` / `CONFIRMED` 状态，不进入 `RESOLVED`。
- 增量 version + 原子 `external_operation.review` audit，记录 actor、reason、evidence、from/to、版本前后、请求/审核时间。
- 只有 `RESOURCE_CONFIRMED`、`NO_RESOURCE_CREATED`、`MANUAL_COMPENSATION_COMPLETED` 可进入 `RESOLVED`；`CONFIRMED` 不允许 `NO_RESOURCE_CREATED`。
- UNRESOLVED 后：仍在待对账列表/全局计数；可再次提交（版本递增）；不能触发 provider 重试；重复审核保留历史审计。
- 测试：队列/计数保留、重复审核、版本竞态、无重试、审计记录。

## 3. P1 — Engine 生命周期 fail-closed

- `Engine.Start(ctx) error`：生命周期恢复失败则不启动任何 Worker，服务不可就绪；main 将其作为致命启动错误。
- `Stop() error`：排空 Worker 后执行停止恢复；失败返回诊断并影响退出；Start 失败后的 Stop 安全 no-op。
- 重复 Start 返回 `ErrEngineAlreadyStarted`；start/stop 状态原子；单实例锁仍是核心约束。
- 测试：恢复失败/无 Worker、重复 Start、Start 失败后 Stop、审计失败恢复回滚。
- **未执行**独立真实 SIGTERM/SIGKILL engine 进程级测试（容器层由 R7/R10 覆盖）；剩余 P3。

## 6. P4 — Cloudflare Live Preflight

- `scripts/cloudflare_preflight.sh` 三模式：
  - **Dry Run（默认）**：无网络、无凭据读取，输出 scope/budget/stop conditions。
  - **Mock Live**：真实 HTTPS 到本地 mock，Bearer 认证、固定 GET `/api/parsed_mails`、TLS 校验、禁止重定向、请求/时间预算；401/403/429/5xx/TLS/redirect 立即停止。
  - **Authorized Read-Only Live**：需 `AUTHORIZED=YES` 授权文件、允许 Host、可读 token 文件；仍只做只读 GET，不含 create/send/delete/DNS/Worker/D1 写入。
- R11 真实执行：Mock Live + dry-run + self-test；**Authorized Live NOT_RUN**（无新授权）。
- 报告字段：authorized_scope、request_budget、requests_used、target_host、tls/auth/readonly/redaction/cleanup/verification_status、stop_reason。
